# Questions ouvertes — relances

## Confirmé

- une relance est préparée dès le lendemain civil de l'échéance effective lorsqu'un solde demeure;
- la génération du brouillon peut être automatique;
- aucun courriel de relance n'est envoyé automatiquement;
- une personne autorisée doit relire et approuver le brouillon;
- le solde, l'échéance, les paiements et le statut de la facture sont revérifiés avant l'envoi;
- un paiement, un nouveau report ou une autre modification pertinente peut rendre le brouillon obsolète;
- l'approbation et l'envoi doivent être auditables.
